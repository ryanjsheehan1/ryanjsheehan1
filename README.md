## Featured Project

### [PrepSignal](https://github.com/ryanjsheehan1/prepsignal) · [Live Demo](https://prepsignal.vercel.app)

AI-powered case interview scoring for MBB candidates. After each mock case, PrepSignal uses Claude to score your performance across 8 consulting dimensions — with verbatim quotes from your own notes as evidence. Track improvement across sessions. Get a personalized drill plan based on your weakest areas.

**Stack:** Next.js 16 · Anthropic Claude · Recharts · TypeScript · Vercel
